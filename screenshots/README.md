## 🎨 Design System Notes

### Color Palette:
- **Background:** #050505 (Luxury Black)
- **Accent:** #9d2235 (Burgundy Red)
- **Text:** White with varying opacity
- **Surface:** Dark gray variants

### Typography:
- **Display Font:** Playfair Display (elegant, serif)
- **Body Font:** Inter / Space Grotesk (modern, sans-serif)
- **Font Weights:** Primarily light (300) for premium feel

### Key Design Elements:
- Glass morphism effects
- Parallax scrolling
- Smooth animations (GSAP, Framer Motion)
- Custom cursor (desktop)
- Magnetic buttons
- Horizontal scrolling sections
- Video backgrounds
- 3D card hover effects

### Viewport Breakpoints:
- Desktop: 1440px+ (captured)
- Tablet: 768px - 1439px
- Mobile: < 768px
